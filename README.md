## 1. Общее описание

Этап 1 представляет собой графический REPL-эмулятор оболочки UNIX-подобной ОС.
Интерфейс реализован на стандартной библиотеке Python Tkinter. Заголовок окна
содержит имя пользователя и имя хоста текущей операционной системы.




## 2. Описание команд

Ввод разделяется на команду и аргументы пробелами (с поддержкой кавычек):

* `ls [аргументы]` — заглушка, выводит имя команды и аргументы;
* `cd [аргументы]` — заглушка, выводит имя команды и аргументы;
* `exit` — завершает работу эмулятора;
* неизвестная команда и некорректные кавычки показывают сообщение об ошибке.




## 3. Запуск

```sh
./run.sh
```

Отдельную проверку парсера и команд можно выполнить так:

```sh
python3 - <<'PY'
from src.Stage_1 import execute_command, parse_command

print(parse_command('ls "folder name"'))
for command in ('ls -l /tmp', 'cd /home', 'unknown', 'exit'):
	print(execute_command(command))
PY
```




## 4. Примеры интерактивной работы

```text
> ls -la /tmp
ls: аргументы: -la /tmp
> cd "my folder"
cd: аргументы: my folder
> mkdir test
Ошибка: неизвестная команда: mkdir
> exit
Завершение работы эмулятора...
```

При вводе незакрытой кавычки отображается ошибка разбора команды.
