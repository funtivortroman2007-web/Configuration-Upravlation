# PR1 — Эмулятор оболочки UNIX-подобной ОС

Учебный проект: графический эмулятор оболочки с виртуальной файловой системой
(VFS) и поддержкой запуска стартовых скриптов.

---

## 1. Общее описание

Эмулятор реализован на Python с использованием стандартной библиотеки Tkinter
(GUI). Заголовок окна формируется на основе реальных данных ОС, в которой
запущен эмулятор, в формате:

Эмулятор - [username@hostname]


Проект развивается поэтапно:

* **Этап 1. REPL** — минимальный прототип с интерактивным диалогом,
  парсером команд и командами-заглушками `ls`, `cd`, `exit`.
* **Этап 2. Конфигурация** — параметры командной строки (`--vfs`, `--script`),
  отладочный вывод параметров при запуске и выполнение стартового скрипта.

* Python 3.10 или новее (используется синтаксис `X | None`).

## 4. Запуск

Все запуски выполняются через единый скрипт `run.sh`:

```sh
./run.sh
```

Скрипт принимает и пробрасывает в приложение все параметры командной строки.

### 4.1. Интерактивный режим (без параметров)

```sh
./run.sh
```

Открывается окно с приглашением `> `. Вводите команды по одной.

### 4.2. Режим стартового скрипта

```sh
./run.sh --script ./src/scripts/start1.txt
```

Эмулятор последовательно выполняет команды из файла, имитируя диалог
пользователя: каждая строка скрипта отображается как ввод (`> команда`),
а результат — как вывод. Ошибочные строки пропускаются, в конце выводится
сводка по строкам с ошибками.

### 4.3. С указанием VFS

```sh
./run.sh --vfs ./src/emu_vfs
```

Путь к VFS используется командой `ls` для отображения реального содержимого
физической директории, играющей роль корня виртуальной файловой системы.

### 4.4. Комбинированный запуск

```sh
./run.sh --vfs ./src/emu_vfs --script ./src/scripts/start1.txt
```

Короткие формы флагов эквивалентны:

```sh
./run.sh -v ./src/emu_vfs -s ./src/scripts/start1.txt
```

## 5. Параметры командной строки

| Параметр       | Короткий | Описание                                       | По умолчанию     |
|----------------|----------|------------------------------------------------|------------------|
| `--vfs PATH`   | `-v`     | Путь к физическому расположению VFS            | не задан         |
| `--script PATH`| `-s`     | Путь к стартовому скрипту                      | не задан         |

Если параметры не заданы, эмулятор стартует в интерактивном режиме.
При запуске в консоль и в GUI выводится отладочный баннер со всеми
фактическими значениями параметров:

```
====================================================
=== Emulator started ===
VFS path:    ./src/emu_vfs
Script path: ./src/scripts/start1.txt
Mode:        script
====================================================
```

## 6. Описание команд

Ввод разделяется на команду и аргументы пробелами (с поддержкой кавычек
через `shlex`).

* `ls [аргументы]` — если задан существующий путь `--vfs`, выводит
  содержимое физической директории; иначе выводит имя команды и аргументы;
* `cd [аргументы]` — изменяет текущую виртуальную директорию (состояние
  хранится в `EmulatorState.cwd`);
* `pwd` — выводит текущую виртуальную директорию;
* `echo [аргументы]` — выводит аргументы через пробел;
* `exit` — в интерактивном режиме закрывает окно, в режиме скрипта —
  прекращает выполнение скрипта;
* неизвестная команда и некорректные кавычки отображают сообщение об ошибке.

---

## 7. Формат стартового скрипта

Стартовый скрипт — обычный текстовый файл (UTF-8), по одной команде
в строке. Правила обработки:

* пустые строки и строки, начинающиеся с `#`, игнорируются;
* каждая команда выполняется последовательно;
* результат выводится в формате, имитирующем диалог:

```
> ls
home  tmp
> cd /home
cd -> /home
> unknown_cmd
Ошибка: неизвестная команда: unknown_cmd
> exit
(скрипт остановлен командой exit)
--- Скрипт завершён с ошибками в строках: [3] ---
```

* ошибочные строки не прерывают выполнение — в конце выводится список
  номеров строк с ошибками;
* если ошибок нет, выводится `--- Скрипт выполнен успешно ---`.

Примеры скриптов лежат в `src/scripts/`:

* `start1.txt` — базовый сценарий без ошибок;
* `start2.txt` — сценарий с ошибочными строками;
* `start3.txt` — сценарий с комментариями и пустыми строками.

## 8. Тестирование параметров командной строки

В каталоге `shell_tests/` лежат shell-скрипты, каждый из которых
запускает эмулятор с определённой комбинацией параметров:

| Скрипт                       | Что проверяет                                |
|------------------------------|----------------------------------------------|
| `test_no_args.sh`            | запуск без параметров (интерактивный режим)  |
| `test_vfs_only.sh`           | только `--vfs`                               |
| `test_script_only.sh`        | только `--script`                            |
| `test_all_args.sh`           | оба параметра (`--vfs` и `--script`)         |
| `test_short_flags.sh`        | короткие формы `-v` и `-s`                   |
| `test_bad_script.sh`         | несуществующий файл скрипта (обработка ошибки) |

Запустить все сразу:

```sh
chmod +x run.sh shell_tests/*.sh
for t in shell_tests/*.sh; do
    echo "########## $t ##########"
    "$t"
    echo
done
```

## 10. Проверка парсера и команд из Python

Отдельную проверку парсера и команд можно выполнить так:

```sh
python3 - <<'PY'
from src.emulator.commands import execute_command, EmulatorState, parse_command

print(parse_command('ls "folder name"'))
state = EmulatorState()
for command in ('ls -l /tmp', 'cd /home', 'pwd', 'unknown', 'exit'):
    ok, out = execute_command(command, state)
    print(f'{command!r:>20} -> ok={ok}, out={out!r}')
PY
```
